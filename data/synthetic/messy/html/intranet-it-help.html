How to request access, rotate API keys, and report phishing

This page covers the three most common IT requests. For anything not listed here, open a ticket in Torchstone Desk.

Request access to a system

  1. Go to Torchstone Desk and choose New Request → Access.
  2. Select the system (e.g. Saltmarsh CRM, Quillbrook Ledger, Nightledger SIEM) and the role you need.
  3. Your manager is auto-added as approver. Most access is granted within one business day.

Rotate an API key

API keys should be rotated every 90 days, and immediately if you suspect exposure.

  1. Sign in to the developer console at console.acme-analytics.example.
  2. Open Settings → API keys and click Rotate next to the key.
  3. Update the secret in Stoneferry CI before the old key expires (24h grace window).
  4. You need the admin role to rotate; viewers cannot. Request the role via Torchstone Desk if needed.

Report a phishing email

If you receive a suspicious message — especially a fake “Acme Billing” invoice notice — do not click any links.

  1. Use the Report Phishing button in your mail client, or
  2. Forward the message to security@acme-analytics.example.
  3. The SOC (Nightledger SIEM) triages reports and will quarantine the campaign.

Questions? Email security@acme-analytics.example or open a Torchstone Desk ticket.
